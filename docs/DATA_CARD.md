# Data card: Commit Suggestor v2 training data

Generated by `uv run python -m commit_suggestor.data_v2` with the counts in `docs/data_v2_stats.json`. The data itself is not distributed: it is built from public repositories under their own open-source licences.

## Source

- 17 training and validation projects (Python), newest 4,000 commits (shallow clone depth) each: 93,635 non-merge commits mined with `git log -p`. The 3 test projects are not used here.
- Split by project: train 15, validation 2 (attrs, typer). The test set is the fixed 450 examples in `eval/test.jsonl` from django-rest-framework, pydantic and sphinx.
- v1, for comparison (from its README; v1 did not commit its counts): 122,088 mined, about 45% kept, 37,898 training examples, of which it trained on 2,400.

- v1 filters: bots, merges, reverts, releases and bumps; subjects of 12-72 characters; at most 4 files; diffs of 40-3,000 characters; lock, minified and binary files removed. PR numbers and CI tags are stripped from subjects.
- v2 adds: generic subjects (`metrics.is_generic`), subjects not in the imperative mood, and near-duplicate diffs (MinHash, Jaccard >= 0.8 on word 5-grams of changed lines), checked against the test and validation diffs first so training loses the copy. Training diffs removed as copies of a test diff: 0.
- 6,353 kept training diffs change too little text (under 5 shingles) for the near-duplicate check; they get the exact-duplicate check only.
- At most 4,000 examples per training project; validation is capped at 600.

## Repo-style context

Each example carries the subjects of the 5 non-merge commits before it (cleaned, each cut to 100 characters). For 50% of examples, fixed per commit, the prompt leaves them out, so the model also works without history. Training takes them from the mined commit order; the test set and the CLI from `git log`, which can differ slightly where history branches.

## Known limitations

- Python projects only, and only their recent history.
- Subjects are the authors' own and are noisy: in a blind rating I scored 21% of test-set author subjects 1 or 2 out of 5 (`eval/rouge_vs_human.md`).
- Diffs over 3,000 characters are dropped, so large changes are not represented.
